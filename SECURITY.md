# Security policy

## Supported versions

kamayoq has no release yet. The project fixes vulnerabilities on the `develop` branch only.

## Report a vulnerability

Do not open a public issue, a discussion, or a pull request for a vulnerability.
Report it in private:

1. Go to the **Security** tab of the repository.
2. Select **Report a vulnerability**.

You can also open <https://github.com/jtdub/kamayoq/security/advisories/new>.

In the report, give this information:

- The affected file or component.
- The steps to reproduce the problem.
- The effect of the problem, for example the data that an attacker can read or change.

## What happens next

kamayoq is pre-alpha, and it has one maintainer. The project gives no fixed response time.
The maintainer replies in the advisory.
The maintainer publishes the advisory after the fix.
